# すうじバスター

3歳向けの、数字を声で答えるスマートフォン用ゲーム。ビルド・外部ライブラリは不要です。

## 起動

`index.html` をブラウザで開くとタップで遊べます。音声は対応ブラウザとマイク許可、通信環境が必要です。スマートフォンに渡す際は、このフォルダの `index.html` と `game.js` を同じ場所にHTTPSで配信してください。PCの localhost でも開発確認できます。

1. 「あそぶ」を押す。
2. 「マイクを オン」を押し、初回は保護者がマイクを許可する。
3. 頭の数字を日本語で言う。ゲーム中は連続で聞き取るため、毎回答のボタン操作は不要です。
4. 正解すると消滅。5体でクリア。数字ボタンでも回答できる。

初期設定は0〜9。保護者メニューで1〜3、1〜5、移動速度も選べます。失敗・攻撃・時間切れはありません。数字の変更は次のゲームから適用されます。

音声認識は Web Speech API を使用し、対応や精度は端末によって異なります。ブラウザの音声認識サービスへ音声が送られる場合があります。アプリ独自の録音・保存・解析サービスはありません。

実機での幼児の発話認識、マイク許可、iOS/Android固有の動作は別途確認が必要です。

## 音声の動作（v2）

途中の認識結果が数字と一致した時点で判定します。途中結果は確定前のため、認識の訂正前に正解になる場合があります。端末・通信による遅延は残ります。無音などで認識が終了した場合は最大3回連続で再接続し、認識結果を受けると回数をリセットします。接続エラーは停止して再操作を案内します。

停止ボタン、5体クリア、保護者設定、画面を離れたときにマイクを停止します。復帰後は手動でオンにしてください。画面外での常時録音は行いません。

検証: node test-game.cjs。0〜9、途中結果、二重判定防止、再接続、停止、権限拒否、クリアを模擬イベントで確認。390×844のブラウザ画面も確認。スマートフォン実機での音声遅延・連続認識は未検証です。

公開先: https://liar0815.github.io/suuji-buster/ （v2）

## アプリアイコン

ゾンビの顔を使ったアイコンを設定しています。ブラウザのタブには `icon.svg`、iPhoneのホーム画面には `apple-touch-icon.png`、Androidなどのインストール用には `icon-192.png` と `icon-512.png` を使用します。画像を作り直す場合は `render-icons.ps1` を実行します。
